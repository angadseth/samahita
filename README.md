# Samahita

Built website of **Samahita** — vrat, tithi and panchang from the Gita Press Narada Purana (#1183), every vidhan with page and line.

Live: https://angadseth.github.io/samahita/

This repository holds only the built site, public error reports (Issues) and app releases. The source is private.

Found a mistake? Press **त्रुटि बताएँ** on any vrat page, or open an issue here with the page and line.
